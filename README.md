## Описание
### Создан класс Product
Класс имеет следующие свойства:
* название (name) тип "str"
* описание (description) тип "str"
* цена (price) тип "float"
* количество в наличии (quantity) тип "int"

Добавлена функции сложения цен одинаковых категорий и изменения цены продукта


### Создан класс Category
Класс имеет следующие свойства
* название (name) тип "str"
* описание (description) тип "str"
* список товаров категории (products) тип "list"
Класс имеет атрибуты:
* счетчик количества категории
* счетчик количества товаров

Добавлена функция добавления продукт к списку продуктов в категории


### Создан класс-наследник Smartphone
Класс имеет следующие свойства
* свойства класса-родителя
* производительность (efficiency) тип "float"
* модель (model) тип "str"
* объем встроенной памяти (memory) тип "int"
* цвет (color) тип "str"


### Создан класс-наследник LawnGrass
Класс имеет следующие свойства
* свойства класса-родителя
* страна-производитель (country) тип "str"
* срок прорастания (germination_period) тип "str"
* цвет (color) тип "str"


### Создан абстрактный-класс BaseProduct
Класс имеет следующие методы
* new_product


### Создан класс-миксин PrintMixin
Класс имеет следующие методы
* init
* repr
